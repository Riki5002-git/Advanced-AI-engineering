## חשבון Langfuse (10 דקות, חינם)

Langfuse הוא שירות בענן שמקבל את ה־traces מהקוד שלך ומציג אותם. התוכנית החינמית (Hobby) מספיקה לכל התרגיל, ולא צריך כרטיס אשראי.

### 1. הרשמה

1. נכנסים ל־https://cloud.langfuse.com.
2. לוחצים **Sign up**. הכי פשוט להירשם עם **Google**. אפשר גם עם מייל וסיסמה, ואז צריך לאשר את המייל שנשלח.
3. אם מופיעה שאלה על אזור (**Region**), בוחרים **EU**. אם כבר נרשמת באזור **US**, גם זה בסדר, רק צריך לזכור את זה לשלב 4.
   איך יודעים באיזה אזור את? לפי הכתובת בדפדפן: `cloud.langfuse.com` הוא EU, ו־`us.cloud.langfuse.com` הוא US.

### 2. ארגון ופרויקט

1. במסך הראשון מתבקשים ליצור **Organization**. נותנים כל שם, למשל השם שלך.
2. אם מופיע מסך של הזמנת חברי צוות (**Invite members**), מדלגים.
3. יוצרים **Project** בשם `ofek-agent`.

### 3. מפתחות

1. בתוך הפרויקט: **Settings** (גלגל השיניים בתפריט הצד) ← **API Keys** ← **Create new API keys**.
2. נפתח חלון עם שלושה ערכים: **Secret Key** (מתחיל ב־`sk-lf-`), **Public Key** (מתחיל ב־`pk-lf-`) ו־**Host**.
3. **מעתיקים את שלושתם עכשיו.** את ה־Secret Key אפשר לראות רק פעם אחת. אם סגרת את החלון לפני שהעתקת, יוצרים זוג מפתחות חדש. זה בסדר.

### 4. הקובץ `.env`

1. בתיקיית התרגיל, מעתיקים את `.env.example` לקובץ חדש בשם `.env` (בדיוק כך: נקודה, ואחריה env, בלי סיומת).
   הכי בטוח מהטרמינל, מתוך תיקיית התרגיל:
   - Windows: `copy .env.example .env`
   - Mac או Linux: `cp .env.example .env`
2. פותחים את `.env` בעורך (VS Code, או Notepad), ומדביקים אחרי ה־`=`, בלי רווחים ובלי מרכאות:
   ```
   LANGFUSE_PUBLIC_KEY=pk-lf-...
   LANGFUSE_SECRET_KEY=sk-lf-...
   LANGFUSE_BASE_URL=https://cloud.langfuse.com
   ```
   באזור US: `LANGFUSE_BASE_URL=https://us.cloud.langfuse.com`. אפשר פשוט להעתיק את ה־Host מהחלון של המפתחות.
3. שומרים.

### 5. בדיקה

```
python check_setup.py
```

צריך להופיע ✓ ליד `the keys work`. אחר כך:

```
python simulate.py --n 1 --fast
```

מחכים חצי דקה, ופותחים ב־Langfuse את **Tracing** ← **Traces**. אם השלמת את שלב 2a, יופיע trace. לפני כן, הרשימה ריקה, וזה תקין.

### אם משהו לא עובד

| מה רואים | מה עושים |
|---|---|
| `no keys: offline mode` | הקובץ `.env` לא נמצא. בודקים שהוא בתיקיית התרגיל (ליד `check_setup.py`), ושהשם שלו `.env` |
| ב־Windows נוצר `.env.txt` | Notepad הוסיף סיומת. משנים את השם מהטרמינל: `ren .env.txt .env` |
| ✗ ליד `the keys work` | המפתחות הוחלפו זה בזה, יש רווח מיותר, או שהאזור לא נכון. משווים ל־Host מהחלון של המפתחות |
| `could not reach Langfuse` | אין אינטרנט, או שרשת חוסמת. אפשר להמשיך במצב offline (למטה) ולהתחבר אחר כך |
| ה־trace לא מופיע | מחכים 30 שניות ומרעננים. בודקים שאת מסתכלת על הפרויקט הנכון (הבורר בראש המסך) |

הקובץ `.env` נשאר רק במחשב שלך. לא שולחים אותו, לא מעלים אותו ל־git, לא מצלמים אותו ולא מגישים אותו. בצילומי המסך של Langfuse לא מופיעים מפתחות, אז אותם אפשר להגיש.

## כלי שורת הפקודה של Langfuse (רשות)

ל־Langfuse יש גם CLI, שקורא ומעדכן את הנתונים בפרויקט ישר מהטרמינל, בלי לפתוח את האתר. נדרש Node.js.
הוא משתמש באותם מפתחות, ואפשר להפנות אותו לקובץ `.env` של התרגיל. לדוגמה, חמשת הצעדים האחרונים שנכשלו:

```
npx @langfuse/cli --env .env api observations list --level ERROR --limit 5
```

רשימת כל הפקודות: `npx @langfuse/cli api --help`, ולכל פקודה `--help` משלה.
הכלי נבנה גם בשביל סוכני קוד: אפשר לבקש מ־Claude Code לחקור דרכו את ה־traces שלך, למשל "מצא את ה־traces עם הכי הרבה שגיאות, והסבר מה קרה בהם".

## שיתוף traces לבדיקה

הפרויקט שלך ב־Langfuse פרטי, ואין למרצה גישה אליו. כדי שאפשר יהיה לבדוק, משתפים שני traces בקישור ציבורי:

1. פותחים ב־Langfuse trace עם קריאה לכלי.
2. לוחצים על התפריט **⋯** בראש ה־trace, ובוחרים **Make Public**. מופיעה הודעה שה־trace שותף, והקישור מועתק.
3. מדביקים את הקישור בראש חלק 1 ב־`REPORT.md`. אם צריך להעתיק שוב: אותו תפריט ← **Copy share link**.
4. חוזרים על זה עם trace שיש בו שגיאה בכלי. מוצאים אותו בסינון **Level = ERROR**.

מי שמקבל קישור כזה רואה את ה־trace המלא בלי להתחבר. לכן משתפים רק traces מהתרגיל. ביטול שיתוף: אותו תפריט ← **Unshare**.

**רשות:** כדי שאפשר יהיה להסתכל בכל הפרויקט שלך, למשל כשנתקעת, מזמינים את המרצה: **Settings** ← **Members**, עם הרשאת צפייה (**Viewer**). התוכנית החינמית מאפשרת שני משתמשים בפרויקט, כך שיש מקום לך ולמרצה.

**בלי חשבון או בלי אינטרנט?** הכול עובד גם בלי מפתחות. ה־traces נכתבים לקובץ `runs/spans.jsonl`, ו־`python trace_view.py` מציג אותם כעץ.
